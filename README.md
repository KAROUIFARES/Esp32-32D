# ESP32 32D Hardware Project

Ce dépôt contient la conception matérielle et les schémas sous **Proteus** pour le module **ESP32-WROOM-32D**.

## Structure du projet

- `ESP32 32D.pdsprj` : Projet Proteus (schéma et routage PCB).
- `Docs/` : Fiches techniques et schémas de référence :
  - `esp32_datasheet_en.pdf` : Datasheet officielle ESP32.
  - `esp32_devkitc_v4_sch.pdf` : Schéma de référence ESP32 DevKitC V4.
- `.gitignore` : Exclusion des sauvegardes automatiques (`Project Backups/`) et des fichiers de session/espace de travail.

## Logiciels requis

- Proteus Design Suite (version supportant les projets `.pdsprj`).
